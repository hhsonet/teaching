# Structured Programming Language

CSE 1112, Structured Programming Language Laboratory, United International University. Live site: https://hhsonet.github.io/teaching/spl/

A 12-session lab in structured C programming. You move from basics, functions and loops through arrays, strings, structures and pointers, and finish with a team project.

## Assessment

Attendance 5, assignment 10, project 10, class performance 25, viva 10, mid-term exam 20, final exam 20. Total 100.
