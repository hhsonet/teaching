# Lectures

12 lectures in 6 units. Lecture pages open on the [course site](https://hhsonet.github.io/teaching/spl/#/lectures) as they are published.

| Lecture | Unit | Details | Deadline |
|---|---|---|---|
| 01 | Basics | Review of ICS: input and output, variables, operators, selection statements, loop | |
| 02 | Function & Loop | Functions with parameters and return values; for, while and do-while loops | |
| 03 | Array | One- and two-dimensional arrays; passing arrays to functions | Class Test 01 (lectures 1 and 2) |
| 04 | String | Character arrays; string library functions such as strlen, strcpy and strcmp | |
| 05 | Review | Practice problems from lectures 1 to 4 | |
| 06 | **Midterm Exam** | Covers lectures 1 to 5 | **Midterm exam** |
| 07 | Structure | Declaring structures, accessing members, arrays of structures | |
| 08 | Structure | Passing structures to functions; nested structures | Class Test 02 |
| 09 | Pointer | Pointer declaration, address and dereference operators | |
| 10 | Pointer | Pointers with arrays, strings and functions | Class Test 03 |
| 11 | Project | Team project: a modular program using structures and functions, file | Team project |
| 12 | **Final Exam** | Covers lectures 7 to 11 | **Final exam** |

See the [syllabus](syllabus.md) for marks and course outcomes.
