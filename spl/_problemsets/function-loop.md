Practice for loops (`for`, `while`, `do-while`) and basic functions.

## Problems

### 1. Print 1 to n (Easy)

Read `n` and print the numbers 1 to `n` on one line.

Example: input `5`, output `1 2 3 4 5`.

### 2. Sum of digits (Easy)

Read a positive integer and print the sum of its digits.

Example: input `482`, output `14`.

### 3. Prime check (Medium)

Write a function `int isPrime(int n)` that returns 1 for a prime and 0 otherwise. Use it to print all primes up to `n`.

Example: input `10`, output `2 3 5 7`.

### 4. Factorial (Medium)

Write a function that returns `n` factorial using a loop. Read `n` and print the result.

Example: input `5`, output `120`.

### 5. Fibonacci (Hard)

Write a function that prints the first `n` Fibonacci numbers.

Example: input `6`, output `0 1 1 2 3 5`.
