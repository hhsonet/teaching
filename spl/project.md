# Project

A team project that applies structures, functions and file handling together in one modular C program.

| Marks | Team size | Lecture | Outcome |
|---|---|---|---|
| 10 of 100 | 3 students | 11 | CO4: work in a team |

## Requirements

- Teams of 3 students build a C program that solves a real-world scenario.
- The project uses structures, functions and file handling together.
- Organize the project using abstraction through structures.

See the [syllabus](syllabus.md) for the full assessment breakdown.
