# CSE 1112: Structured Programming Language Laboratory

A 12-session lab in structured C programming. You move from basics, functions and loops through arrays, strings, structures and pointers, and finish with a team project.

| Day | Time | Room |

## Prerequisites

| Course | Why it matters |
|---|---|
| Introduction to Computer Systems (ICS) | Lecture 1 builds on input and output, variables, operators and selection statements from ICS. |

## Course outcomes

| CO | Description |
|---|---|
| CO1 | Describe the structured programming language features. |
| CO2 | Design, compile and execute software programs to solve basic to moderate problems using a popular IDE. |
| CO3 | Implementation of modular programs using different data structures like array, structures. |
| CO4 | Work in a team and organize a project using abstraction through structures. |

## Course plan

| Lecture | Topic | Details | CO |
|---|---|---|---|
| 1 | Basics | Review of ICS: input and output, variables, operators, selection statements | CO1, CO2 |
| 2 | Function & Loop | Functions with parameters and return values; for, while and do-while loops | CO1, CO2 |
| 3 | Array | One- and two-dimensional arrays; passing arrays to functions. **Class Test 01** (lectures 1 and 2) | CO2, CO3 |
| 4 | String | Character arrays; string library functions such as strlen, strcpy and strcmp | CO2, CO3 |
| 5 | Review | Practice problems from lectures 1 to 4 | CO1, CO2 |
| 6 | **Midterm Exam** | **Covers lectures 1 to 5** | CO1, CO2 |
| 7 | Structure | Declaring structures, accessing members, arrays of structures | CO3 |
| 8 | Structure | Passing structures to functions; nested structures. **Class Test 02** | CO3 |
| 9 | Pointer | Pointer declaration, address and dereference operators | CO1, CO3 |
| 10 | Pointer | Pointers with arrays, strings and functions. **Class Test 03** | CO1, CO3 |
| 11 | Project | Team project: a modular program using structures and functions, file | CO4 |
| 12 | **Final Exam** | Covers lectures 7 to 11 | CO2, CO3 |

## Assessment

| Assessment type | Marks | Details |
|---|---|---|
| Attendance | 5 | Full marks for attending 10 or more classes; 2 absences ignored |
| Assignment | 10 | 10 weekly progress logs, 1 mark each |
| Project | 10 | Team project (CO4) |
| Class performance | 25 | Base score, plus bonus for assignments and active participation |
| Viva | 10 | Oral assessment |
| Mid-term exam | 20 | Covers lectures 1 to 5 |
| Final exam | 20 | Covers lectures 7 to 11 |
| **Total** | **100** | |

- **Class performance:** calculated from the best 2 of the 3 class tests as the base. Additional marks may be awarded for assignments and active participation in class activities.
- **Project:** teams of 3 students build a C program that solves a real-world scenario. The project uses structures, functions and file handling together.

## Policies

| Policy | Details |
|---|---|
| Attendance | Attend at least 10 of the 12 classes for full attendance marks. 2 absences are ignored. |
| Late work | Submit weekly progress logs and the project by the stated deadline. Late work may lose marks. |
| Class tests | The best 2 of 3 class tests count. Missed tests are not retaken unless the instructor approves. |
| Academic integrity | Write your own code. Copying code from classmates or online, or sharing yours, is plagiarism and is reported under university rules. |
| Teamwork | Every team member must contribute to the project. Marks may differ between members. |
