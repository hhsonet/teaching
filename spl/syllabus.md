# CSE 1112: Structured Programming Language Laboratory

A 12-session lab in structured C programming. Marks are split across attendance, assignments, a project, class performance, viva and two exams, totaling 100.

## Reference books

1. *Programming in ANSI C* (5th edition or later), E. Balagurusamy
2. *Teach Yourself C*, Herbert Schildt

## Course outcomes

| CO | Description |
|---|---|
| CO1 | Describe the structured programming language features. |
| CO2 | Design, compile and execute software programs to solve basic to moderate problems using a popular IDE. |
| CO3 | Implementation of modular programs using different data structures like array, structures. |
| CO4 | Work in a team and organize a project using abstraction through structures. |

## Course plan

| Lecture | Topic | Details |
|---|---|---|
| 1 | Basics | Review of ICS: input and output, variables, operators, selection statements |
| 2 | Function & Loop | Functions with parameters and return values; for, while and do-while loops |
| 3 | Array | One- and two-dimensional arrays; passing arrays to functions. **Class Test 01** (lectures 1 and 2) |
| 4 | String | Character arrays; string library functions such as strlen, strcpy and strcmp |
| 5 | Review | Practice problems from lectures 1 to 4 |
| 6 | **Midterm Exam** | **Covers lectures 1 to 5** |
| 7 | Structure | Declaring structures, accessing members, arrays of structures |
| 8 | Structure | Passing structures to functions; nested structures. **Class Test 02** |
| 9 | Pointer | Pointer declaration, address and dereference operators |
| 10 | Pointer | Pointers with arrays, strings and functions. **Class Test 03** |
| 11 | Project | Team project: a modular program using structures and functions, file |
| 12 | **Final Exam** | Covers lectures 7 to 11 |

## Assessment

| Assessment type | Marks | Details |
|---|---|---|
| Attendance | 5 | Full marks for attending 10 or more classes; 2 absences ignored |
| Assignment | 10 | 10 weekly progress logs, 1 mark each |
| Project | 10 | Team project (CO4) |
| Class performance | 30 | Base score, plus bonus for assignments and active participation |
| Viva | 10 | Oral assessment |
| Mid-term exam | 20 | Covers lectures 1 to 5 |
| Final exam | 20 | Covers lectures 7 to 11 |
| **Total** | **100** | |

### Evaluation details

- **Class performance:** calculated from the best 2 of the 3 class tests as the base. Additional marks may be awarded for assignments and active participation in class activities.
- **Project:** teams of 3 students build a C program that solves a real-world scenario. The project uses structures, functions and file handling together.
