# Materials

Course files, tools and links, plus slides, notes and readings for every lecture.

## Course files

- [Problem sets](https://drive.google.com/drive/folders/1tE0oCDc2jl17sWwwA08xo1x9ykkj9sIu?usp=drive_link): topic-wise C problems
- [Code](code/): example programs, one folder per lecture
- [Super Simple C](https://docs.google.com/presentation/d/1cxrnU-0y0p0pd4w1PfB-6gL7NcBBKg1Q/edit?usp=drive_link): slide deck introducing C programming
- [Programming in ANSI C](https://drive.google.com/file/d/1u0pgbXTC7BGAHU0Z-ncumaTCAC964hsq/view?usp=sharing): E. Balagurusamy, 5th edition or later
- *Teach Yourself C*: Herbert Schildt

## Tools and references

- [GCC compiler](https://gcc.gnu.org/install/): download and install instructions
- [Code::Blocks](https://www.codeblocks.org/downloads/binaries/): free C IDE, download the installer with GCC (mingw-setup)
- [Online C compiler](https://www.onlinegdb.com/online_c_compiler): run code in the browser, no setup
- [C reference](https://en.cppreference.com/w/c): language and library reference
